# Gama Institute

Website for Gama Institute — a research and training institute at the intersection of software engineering and artificial intelligence.

Built with Vite + React 18 + TypeScript, statically generated with vite-react-ssg, deployed to Cloudflare Pages. Bilingual (French default / English toggle), dark-mode-ready.

## Quick start

```bash
npm install
npm run dev          # local dev server
npm run build        # SSG build → dist/
npm run preview      # serve the dist/ build locally
npm run type-check   # TypeScript — covers src/ and functions/
```
