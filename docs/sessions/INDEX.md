# Session index

Newest first. Not every session needs an entry — write one only when the session produced a decision worth preserving, left something deferred, or produced handoff context another contributor would need.

## Session template

```md
# Session — YYYY-MM-DD

## Goal
One sentence.

## Changes
- Bullet list of what was done.

## Decisions
- Any decisions made; link to ADRs or DECISIONS.md entries if written.

## Deferred
- What was intentionally left out, why, and the trigger for picking it back up.

## Next session
One sentence on the suggested starting point.
```
